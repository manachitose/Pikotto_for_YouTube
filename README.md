# Pikotto for YouTube

YouTubeで見ている瞬間を、ワンクリックでスクリーンショット保存できるChrome拡張機能です。

## インストール方法

この拡張機能はビルド不要です。GitHubからダウンロードして、そのままChromeに読み込めます。

1. GitHubの「Code」→「Download ZIP」を選ぶ
2. ダウンロードしたZIPファイルを展開する
3. Chromeで `chrome://extensions` を開く
4. 右上の「デベロッパーモード」をオンにする
5. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
6. 展開したフォルダ内の `extension` フォルダを選ぶ

初回読み込み時に「はじめに」が開きます。ブラウザ右上の拡張機能アイコン（パズルのピース）からPikotto for YouTubeをツールバーに固定しておくと、いつでもサイドパネルを開けます。

## 使い方

YouTubeの動画またはShortsを開き、プレイヤー上の撮影ボタンか、サイドパネルの「今すぐ撮影」を押してください。撮影した画像はダウンロードフォルダ内の `Pikotto_for_YouTube` フォルダに保存されます。

設定パネルでは、保存形式、ランダム撮影、予約撮影、連写撮影も設定できます。

## 対応ブラウザ

Google Chromeの最新版を推奨します。
