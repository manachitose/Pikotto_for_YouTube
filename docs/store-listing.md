# Chrome Web Store 掲載用テキスト(下書き)

## 拡張機能名
Pikotto for YouTube | ピコット

## 概要(132文字以内)
YouTube再生中の動画をワンクリックでスクリーンショット撮影。連写・ランダム撮影・予約撮影にも対応した動画キャプチャツール

## 詳細説明
Pikotto for YouTubeは、YouTubeの動画・Shorts視聴中に「今見ている瞬間」を手軽にスクリーンショット保存できるChrome拡張機能です。

動画プレイヤー上のボタンをワンクリックするだけで、再生中のフレームをPNGとしてローカルに自動保存します。手動撮影だけでなく、ランダムなタイミングでの自動撮影や、指定時刻での予約撮影にも対応しています。

【主な機能】
・動画プレイヤー上のワンクリックボタンでその場を撮影
・YouTube Shorts にも対応
・ランダム撮影(◯枚/時のペースで自動撮影)
・予約撮影(指定した時刻に自動撮影)
・連写撮影(1回のトリガーで指定枚数を短間隔で連続撮影、予約撮影・ショートカットボタン・手動撮影に適用可能)
・撮影画像は「ダウンロード/Pikotto_for_YouTube/」フォルダにファイル名(動画タイトル+日時)付きで自動保存
・サイドパネルUIで各種設定をいつでも確認・変更可能

【プライバシーについて】
撮影した画像はブラウザのダウンロード機能でユーザーのPCに直接保存されます。画像や設定情報が外部のサーバーに送信されることは一切ありません。

## 権限の説明(審査時に聞かれる項目)

### host_permissions: *://*.youtube.com/*
YouTubeの動画/Shortsページで再生中の`<video>`要素からフレームを取得し、キャプチャボタンを表示するために必要です。YouTube以外のサイトにはアクセスしません。

### downloads
撮影したスクリーンショット(PNG)をユーザーのPCにローカル保存するために使用します。

### storage
ランダム撮影・予約撮影・連写設定などのユーザー設定をブラウザ内にローカル保存するために使用します。外部送信は行いません。

### alarms
ランダム撮影・予約撮影を指定のタイミングで実行するために使用します。

### sidePanel
撮影設定(ランダム撮影/予約撮影/連写設定)を操作するUIをサイドパネルとして表示するために使用します。

## 単一の目的の説明(Single purpose)
YouTube視聴中の動画フレームをスクリーンショットとして撮影し、ユーザーのPCにローカル保存すること。
